# Separating Genetic and Protein Evidence in Open Targets

Code and data for:

> Ye Ye. **Separating Genetic and Protein Evidence in Open Targets: An Auditable Re-ranking Study.**
> IEEE BIBM 2026 Workshops (paper S20209).

The study re-ranks the Open Targets top-150 associations for Alzheimer disease (AD, `MONDO_0004975`)
and Parkinson disease (PD, `MONDO_0005180`). Genetics-linked evidence and protein-oriented evidence
(tractability, RNA expression, animal models, literature) are scored in separate channels and combined
by late fusion, with an optional, explicit post-ranking rule. Everything is deterministic: there is no
training step, and the same cached inputs always give the same ranking.

## Contents

| Path | Description |
|---|---|
| `run_analysis.py` | Scoring, rankings, and figures (main tables and Figs. 2–4) |
| `sensitivity_analysis.py` | Genetics-only baseline, protein-channel ablation, fusion-weight sweep, weight and threshold sensitivity (Table IV, Section VI-E) |
| `data/ot_ad.json`, `data/ot_pd.json` | Cached Open Targets Platform GraphQL responses (top 150 associations, retrieved 18 September 2026) |
| `results/scores_ad.csv`, `results/scores_pd.csv` | Per-gene channel scores, fused scores, and labels |
| `figures/` | Figures as generated by `run_analysis.py` |

## Reproduce

```bash
pip install -r requirements.txt
python run_analysis.py          # prints the ranking report, rewrites results/ and figures/
python sensitivity_analysis.py  # prints the baseline, ablation, and sensitivity results
```

The scripts read the cached JSON files in `data/`. If a cache file is deleted, `run_analysis.py`
re-queries the Open Targets API; because the platform is updated regularly, a fresh query may
return different scores from the snapshot used in the paper.

## Data source

Association scores come from the [Open Targets Platform](https://platform.opentargets.org/) GraphQL API.
Please cite Open Targets (Ochoa et al., *Nucleic Acids Res.* 2023) when using these data.
